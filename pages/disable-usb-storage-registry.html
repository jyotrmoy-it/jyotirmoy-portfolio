Disable USB Storage Devices Through the Registry

A quick Windows registry setting can prevent standard USB mass-storage devices, such as flash drives, from being used on a PC.

USB STORAGEACCESS RESTRICTED
USBSTOR Start = 4

Want to restrict users from copying data to or from USB flash drives? You can disable the Windows USB mass-storage driver by changing a registry value. This can help reduce unauthorised data transfers and limit one possible route for introducing malware through removable storage.

Important: this does not disable every USB port.

This setting targets USB mass-storage devices, such as USB flash drives and many external USB drives. USB keyboards, mice and other USB device types may continue to work. It is not a complete data-loss-prevention or malware-protection solution.

Before you begin

  • Sign in with an account that has local administrator permissions.
  • Back up the relevant registry key before making changes. In Registry Editor, right-click the USBSTOR key and select Export.
  • On a company-managed computer, check with your IT or security team first. Group Policy or device-management policies may control or overwrite this setting.

How to disable USB storage

  1. Open the Run dialog

    Click Start, search for Run, or press Windows + R.

  2. Launch Registry Editor

    Type regedit and press Enter. Approve the User Account Control prompt if it appears.

  3. Navigate to the USB storage registry key

    In Registry Editor, browse to the following location:

    HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\USBSTOR

  4. Find the Start value

    In the right-hand pane, double-click the Start DWORD (32-bit) value.

  5. Disable the USB storage driver

    In Value data, enter 4. Leave the base as Hexadecimal unless your environment specifies otherwise, then select OK.

    Start = 4

  6. Close Registry Editor and restart Windows

    Close Registry Editor and restart the computer so the change can take effect. Test with an approved USB storage device.

How to re-enable USB storage

To restore the usual USB mass-storage driver setting, return to the same registry location:

HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\USBSTOR

Double-click Start, change Value data to 3, select OK, and restart Windows.

4USB storage disabledUSB mass-storage driver is prevented from starting.
3USB storage enabledTypical default start setting for USB mass storage.

Compatibility and security notes

  • This method is documented by Microsoft for managing USB storage on Windows. The exact behaviour can vary by Windows version, device state and organisation policy.
  • Microsoft's current administrative guidance describes setting USBSTOR\Start to 4 and notes that a restart is required. The typical default value is 3.
  • This is not the same as disabling the physical USB controller or every USB port. Other device classes may remain available.
  • For centrally managed business devices, use approved Group Policy, Microsoft Intune or your organisation's endpoint-security controls for broader and auditable removable-storage restrictions.
Use this carefully

Incorrect registry changes can cause system problems. Export the key first, make only the change described here, and keep a record of the original value so you can restore it if needed.

Reference: Microsoft — Administrative Guidance, Managing USB.
