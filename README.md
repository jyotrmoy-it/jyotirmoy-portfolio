# Byte By Jyotirmoy

A lightweight, multi-page professional portfolio for Jyotirmoy Mukherjee.

## Stack
- Semantic HTML
- Shared CSS
- Vanilla JavaScript
- Static hosting

## Structure
- `index.html` — homepage
- `pages/` — About, Expertise, Experience, Projects, Knowledge Hub and Contact
- `css/style.css` — shared styles
- `js/main.js` — accessible mobile navigation and small UI enhancements
- `sitemap.xml` and `robots.txt` — basic search-engine discovery

## Local preview
Open `index.html` in a browser. No build step or package installation is required.

## Content policy
Employer names, employment dates, detailed skills, achievements, external profile URLs and CV downloads should be added only after verification and approval. Keep confidential company, customer and infrastructure information out of public case studies.
